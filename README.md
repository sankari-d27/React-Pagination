# React Pagination

A simple pagination application built using **React.js**. This project demonstrates how to display a collection of posts across multiple pages with navigation controls like Start, Previous, Next, and End.

##Project Link: https://sankari-d27.github.io/React-Pagination/

## 📌 About The Project

This project implements pagination functionality using React Hooks.  
The application displays a list of posts and divides them into smaller pages. Users can easily navigate through pages using pagination buttons.

The project uses React state management to track the current page and dynamically update the displayed posts.

## ✨ Features

- Display posts with pagination
- Navigate using:
  - Start button
  - Previous button
  - Page number buttons
  - Next button
  - End button
- Active page highlighting
- Disabled navigation buttons when reaching first or last page
- Maintains consistent list height using empty placeholders
- Responsive and simple UI design
